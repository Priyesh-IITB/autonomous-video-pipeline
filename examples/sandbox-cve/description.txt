DeepSeek Harness (dsh) agents could switch their own sandbox to danger-full-access with one shell command: no approval prompt, and the log said the user did it. Here's how CVE-2026-82533 worked, what the fix changed, and what it still doesn't cover.

If you run dsh: update to 0.1.2-alpha.2 or later.
